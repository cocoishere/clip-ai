## 在 Chrome 完成验收

1. 在 chrome://extensions 加载 dist，确认无错误；点击工具栏图标可打开侧栏。Chrome 116+。
2. 不填 Key 尝试分析，确认提示配置；填写自己的 Key 并测试连接。测试成功后保存。用无效 Key/模型再次测试，确认提示明确且设置内容不丢失。恢复有效配置。
3. 在公开小红书笔记页点击 CONTENT RADAR。核对标题、正文、来源与实际页面一致，没有把推荐笔记当主文；互动量没有读到时显示未获取。失败则粘贴正文继续。
4. 设置真实产品信息，发起分析，确认恰好三个新选题、功能不足标记待核实；编辑一个选题，取消勾选另一个，保存后导出研究和选题两张 CSV，Source Note ID 关联且只导出已选择选题。
5. 在普通网页选中文字，右键 Save to CLIP//AI → Analyze as Feedback，确认侧栏填入准确选文且没有自动上传；无法打开时点图标进入。提炼、编辑、保存、复制并导出。
6. 手动粘贴“每次都要一条一条修改，太麻烦了。”，检查事实和推测的区分，初始状态 Pending Review，不能凭空增加 Excel 同步等要求。短文本不足 5 字符应被拒绝。
7. 请求过程中取消；使用浏览器断网模拟网络故障；超时错误已用单元测试模拟，实际等待时观察 Chrome 是否先结束 worker。确认输入保留、按钮可重试。
8. 保存多条后批量导出，在 WPS 表格查看中文、换行、引号与公式风险文本均作为文字；导入多维表格检查列映射。
9. 历史记录查看、单条删除、清空；清空前可取消。达到 200 条时明确拒绝继续保存，不应静默删除旧记录。
10. 默认存 session Key，关闭整个 Chrome 后应需重新填写；开启 Remember Key 后重启可用；Remove Key 后两处均无 Key。检查扩展可信存储，不要截图泄露 Key。
11. 导航或刷新网页后重新点击图标授权再采集，受限系统页面需提示手动输入。测试系统减少动画、手动 Reduced Motion 和窄侧栏。
12. Chrome 扩展管理页重新加载 worker，确认本地结果可读；请求中被终止时应提示连接中断且保留侧栏内输入。关闭侧栏会丢失未保存表单，不提供后台恢复。
