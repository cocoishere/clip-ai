# 隐私说明草案

CLIP//AI 无自有遥测和开发者数据服务器。只有用户点击采集后才读取当前页面的可见文字、标题、URL、公开标签或用户选文。用户可编辑后再提交。不要采集私人消息或敏感个人数据。插件不会读取 Cookie、密码或隐藏表单，不进行后台浏览记录扫描。

点击分析会将已确认文本、来源信息、用户填写的目标产品资料发送到 OpenAI API。API 数据由服务商政策处理；store=false 不代表所有服务商日志零留存。费用由用户自己的账户承担。API Key 仅在扩展可信上下文使用，默认存储于浏览器 session，主动 Remember Key 后可持久保存在 local。客户端存储并非服务器端密钥保险库。

分析结果不会自动保存。用户确认保存后的研究、选题、反馈原话、来源与时间仅保存在设备，最多 200 条主记录。不会默认保留完整网页正文。可删除单条或清空全部。CSV 是用户主动下载到本地的文件，插件无法自动删除已下载文件。V1 不向 WPS 自动上传。

公开发布前，开发者需补充真实运营主体、联系渠道、生效日期，并将本说明部署到可公开访问的隐私政策地址。

v1.1.0 更新：用户可选择 OpenAI 或 DeepSeek。内容仅发送到当前已保存服务商的官方 API；对应账户承担费用。两个服务商的 Key 独立保存，不跨服务商发送。Remove Key 删除当前服务商的会话及持久 Key，另一家服务商的 Key 需切换后分别删除。新增固定网络权限 api.deepseek.com，无任意自定义 API 地址。

v1.1.1 新增可选的小红书域名访问权限（https://*.xiaohongshu.com/*），仅在用户点击「授权读取小红书」并通过 Chrome 授权后生效。它是可保留的站点权限，可在扩展详情的网站访问权限中撤销。插件仍不会后台扫描或批量采集，正文读取由用户点击触发。
