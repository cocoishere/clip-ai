CLIP//AI — From Content to Insights.

首个公开版本，支持将网页内容转为内容拆解与三个运营新选题，将用户反馈提炼为痛点与潜在需求。

- Content Radar 与 Idea Remix
- Feedback Radar 与选文右键采集
- OpenAI / DeepSeek BYOK
- 可编辑预览、本地历史、复制与导出
- 深色 Chrome Side Panel

安装：下载 ZIP 并解压 → chrome://extensions → 开发者模式 → 加载已解压的扩展程序 → 选择包含 manifest.json 的文件夹。

需要自行配置服务商 API Key。尚未上架 Chrome Web Store。本版不含配图 OCR 或 WPS 云端同步。
