# WPS Phase 2 接入准备

核对日期：2026-10-30。V1 只有 CSV；src/wps.ts 是类型契约，没有伪造的云端成功响应。

## 已确认的官方能力

[WPS365 产品简介](https://365.kdocs.cn/3rd/open/documents/app-integration-dev/wps365/server/introduce) 列出多维表数据表/字段/视图/记录管理能力及云文档文件管理能力。

[创建记录官方页](https://open.wps.cn/documents/app-integration-dev/wps365/server/dbsheet/records/create-record) 明确支持应用及用户授权，需有效 access_token、kso.dbsheet.readwrite、目标文件写权限、file_id 和 sheet_id，并使用 KSO-1 请求签名。请求非幂等，重复调用会新增记录，需要业务层去重。

## 仍需应用凭证和官方可访问文档验证

本环境未登录开放平台，也无开发者应用和 WPS 授权。部分官方链接返回空页、404 或超时，因此以下尚未完成接口级验证，不能编造实现：

| 能力 | 接入前需确认 |
| --- | --- |
| 用户授权 | 应用类型、授权入口、回调配置、授权码与令牌交换、刷新撤销机制 |
| 选择已有文件 | 用户文件选择器或授权后的列表接口、个人版/企业版范围 |
| 读取表和字段 | Schema 获取接口的当前参数与返回值、字段类型映射 |
| 创建数据表和字段 | 产品总览确认有能力；具体请求/权限需打开当前接口页并验证 |
| 写入记录 | 官方创建记录页已确认要求；需真实 token、签名、测试表验证 |
| 更新/去重 | 以 Source Note ID 与选题 ID 建索引，重试前查重；验证查询过滤语义 |
| 新建完整多维表文件 | 不能由“创建数据表”推导为“创建文件”；需确认云文档创建文件是否支持 db/.dbt 及应用权限 |

## 安全实现方案

扩展 → 自有认证后端 → WPS OpenAPI。后端管理 AppSecret、KSO-1 签名、用户令牌交换及刷新；敏感凭证绝不打包进扩展。扩展只访问已配置的固定后端，用户授权后选择文件/数据表，后端读取字段并返回可确认的映射预览。新增和更新请求使用本地记录 ID 幂等账本，并提供明确失败状态。申请并审核最小权限后才能联调。没有真实授权时 Connect WPS 不应表现为已连接。

后端实现 src/wps.ts 的 WpsAdapter 契约；发布下一阶段之前为上述每项补上官方具体页、真实请求证据和授权撤销测试。
